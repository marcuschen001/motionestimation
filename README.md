This Jupyter Notebook is a simulator of the motion estimation scheme commonly used in the MPEG-2/H.262 standard of the "generic coding of moving pictures and associated audio information." I have provided an example GIF but you can be able to upload your own GIF's to use in this notebook as well (I would keep it below 10-15 frames though). 

To use this notebook, I'd recommend having OpenCV, numpy, matplotlib, scipy, Pillow, and patchify installed, which can be done using pip. More details of the specifics and details will be included on my [blog](https://chennrobotics.wordpress.com/) about the MPEG standard. Happy coding!
